# FlanCommand 98.css Theme Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a faithful local Windows 98 98.css-style theme as a new option while preserving all existing themes and behavior.

**Architecture:** Extend the existing theme union, shared names, and cycle list with `win98css`. Add one CSS layer keyed to `html[data-theme="win98css"]` after the current theme layers so it can fully control Windows 98 surfaces without affecting System 6 or BOOTSTRA.386. Keep the current static shell and responsive interaction model.

**Tech Stack:** TypeScript settings normalization, vanilla browser JavaScript, static HTML, CSS, Vitest, Playwright.
