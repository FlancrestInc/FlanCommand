# 7.css Theme Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a local Windows 7/7.css-inspired theme that works in the settings picker and top-right theme cycle without changing app behavior.

**Architecture:** Extend the existing string-based theme registry and settings normalization. Add one scoped CSS layer under `html[data-theme="win7css"]`, using local Aero colors and control states so it wins over earlier theme layers without affecting them. Update browser metadata and service-worker cache freshness with the existing shell pattern.

**Tech Stack:** TypeScript API settings, static HTML/CSS/JavaScript shell, Vitest, Playwright, service worker.
